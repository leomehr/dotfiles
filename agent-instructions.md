# Global agent preferences

- Read repository-specific instructions before changing files.
- Preserve unrelated user changes and keep edits scoped to the request.
- Prefer the repository's existing tools and conventions.
- Use `rg` for text search and `rg --files --hidden` for file discovery.
- Never place credentials, tokens, passkeys, or private keys in source control.
- Ask before destructive operations, publishing, or contacting external people.
- Verify changes with the smallest relevant tests and report what was not tested.
- Do not commit unless explicitly asked.
